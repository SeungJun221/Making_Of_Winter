# 다운받은 후
1. ZIP 파일 전체를 원하는 폴더에 압축 해제.
2. Maya의 File → Set Project에서 Winter_Story_background_Project 폴더를 지정.
3. File > Open Scene으로 scenes/Winter_Story_background.mb를 열기.
4. 뷰포트에서 키보드 6을 눌러 텍스처 표시 켜기.

scenes와 sourceimages 폴더를 함께 보관해 주세요. .mb 파일만 따로 전달하면 텍스처 이미지가 포함되지 않습니다.
